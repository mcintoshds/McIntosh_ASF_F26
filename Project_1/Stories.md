# Neon Black Market User Stories
//Reminder: ## used for increasing heading size

## User Story 1
Fragment: “Products must be tied to vendors.”
As an administrator, I want every product linked to a vendor so that I know who owns what.

## User Story 2
Fragment: “Why can I not see my past purchases?”
As a buyer, I want to view my previous purchases so that I can keep track of the products I bought.

## User Story 3
Fragment: “Transaction shows complete but no product access.”
As a buyer, I want product access to be recorded after purchasing so that I get what I paid for.

## User Story 4
Fragment: “Charged twice for the same item.”
As a buyer, I want each purchase to have a unique reference number so that duplicate transactions can be detected and prevented.

## User Story 5
Fragment: “I want to read reviews before buying.”
As a shopper, I want to read product reviews and ratings so that I can make informed decisions on my purchases.

## User Story 6
Fragment: “Are reviews tied to real users?”
As a shopper, I want reviews to show whether they were submitted by verified users so that I can better identify trustworthy feedback.
